# AIDR – An AI-Powered Document Reading System

This repository now defines the project as an **AI-powered document reading system** focused on helping users quickly understand long or complex documents.

## Core Capabilities

- Document ingestion for common formats (PDF, DOCX, TXT)
- Text extraction and preprocessing
- AI-driven summarization of full documents and sections
- Question answering over uploaded document content
- Key insight extraction (entities, topics, highlights)

## High-Level Flow

1. Upload a document
2. Extract and clean text
3. Chunk and index content
4. Run AI-powered summarization and analysis
5. Ask natural-language questions and receive grounded answers

## Goal

Deliver a lightweight, extensible base for building intelligent document-reading workflows powered by modern language models.
